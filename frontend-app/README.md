# Personal Sous Chef — Flutter client

The mobile client for the Personal Sous Chef / Calotter team project and its personal continuation.

See the [repository README](../README.md) for the project background, setup instructions, validation status, and known limitations.

The application includes household inventory, recipes, guided cooking, nutrition views, and native camera/voice/vision integrations. The trained ingredient model is bundled in `assets/models/`; retraining is not required.

This cleaned copy has not yet been built or tested end to end. Configure the backend address in `lib/core/config/api_config.dart` for your development device. Keep the client cloud API key empty; never commit real credentials.
